# papers/

Put the research papers (PDF files) for the chatbot in this folder. Subfolders are fine
(the chatbot looks in all of them), e.g. `Hybrid Intelligence/` and `Pro AI/`.

**The PDFs themselves are not uploaded to GitHub.** Most research papers are protected by
copyright, so they stay on the computer only (see `.gitignore`). Only this README (the list of
papers) and `titles.txt` (titles set by hand) are uploaded.

To rebuild the chatbot, collect the papers listed below, put them in the folders shown, and run
`python ingest.py`.
