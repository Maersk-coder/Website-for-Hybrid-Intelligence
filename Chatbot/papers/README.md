# papers/

Put the research papers (PDF files) for the chatbot in this folder.

**The PDFs themselves are not uploaded to GitHub.** Most research papers are protected by
copyright, so they stay on the computer only (see `.gitignore`). This README is the only file
in the folder that is uploaded.

To rebuild the chatbot, collect the papers listed below, put them in this folder and run
`python ingest.py`.
